# 2027 ISF 참석 수요조사 웹사이트

| 파일 | 내용 | 자주 고치는 곳 |
|---|---|---|
| index.html | 화면 문구·구성 | 안내 문구, 개인정보 동의서 문구, 문의처 |
| style.css | 색·폰트·PC/모바일 배치 | 맨 위 `:root` 색상 값 |
| app.js | 버튼 동작, 서버 연결 | 맨 위 `CONFIG` (서버 주소, 조사 기간 문구) |
| assets/ | 포스터, 로고 이미지 | 같은 이름으로 덮어쓰기 |

- 동반 한도·마감일·관계 선택지는 이 파일들이 아니라 구글 시트 '설정' 탭에서 바꿉니다.
- Apps Script를 새 주소로 배포했다면 app.js의 `API_URL`만 바꾸면 됩니다.
